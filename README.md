# TDT4195 – Image Processing

This repository contains implementations and experiments developed during the TDT4195 Image Processing course.

The repository contains three assignments:

- **Assignment 1:** Basic spatial filtering, convolution, grayscale images, and fully connected neural networks.
- **Assignment 2:** Convolutional neural networks and image filtering in the frequency domain.
- **Assignment 3:** Image segmentation, thresholding, region growing, and binary morphological operations.

The work is organized by assignment. Each assignment contains Jupyter notebooks, supporting Python utilities, input images, and selected processed results.
